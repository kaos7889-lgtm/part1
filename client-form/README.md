# 상세페이지 제작 사전 질문지 (구글 폼)

`createDetailPageForm.gs`를 실행하면 구글 폼이 자동으로 만들어집니다.

## 만드는 방법 (약 1분)
1. https://script.google.com 접속 → **새 프로젝트**
2. 기본 코드를 지우고 `createDetailPageForm.gs` 내용을 붙여넣은 뒤 저장
3. 함수 `createDetailPageForm` 선택 → **실행** → 구글 계정 권한 승인
4. **실행 로그**에 출력된 링크 확인
   - 응답용 링크 → 클라이언트에게 전달
   - 편집용 링크 → 문구·디자인(테마 색상, 헤더 이미지) 수정
   - 응답 스프레드시트 → 받은 답변이 자동으로 정리됨

## 폼 구성
| 섹션 | 내용 |
|---|---|
| 1. 작업 기본 정보 | 브랜드명, 담당자, 판매처(복수 선택 + 기타), 제품 수·제품명, 오픈 희망일 |
| 2. 레퍼런스 | 좋아하는 상세페이지 + 이유, 피하고 싶은 스타일, 벤치마킹 브랜드 |
| 3. 브랜드 정보 | 로고, 브랜드 소개, 컬러, 고객층, 분위기 키워드, 폰트·슬로건, SNS·가이드북 |
| 4. 제품 정보 | 제품별 섹션(기본 3개). 각 제품 끝에서 "추가 제품 있음/없음"으로 다음 제품 또는 5번으로 이동 |
| 5. 이미지 소스 | 단독 컷, 착용 컷, 원본, 연출컷, 패키지 컷 (공유 링크) |
| 6. 구매 안내 정보 | 배송, 교환·반품, A/S, 관리 방법, 사이즈 측정법, 선물 포장 |
| 7. 기타 | 자주 묻는 질문, 추가 전달 사항 |

- [필수] 항목은 응답 필수로 설정되어 있습니다(관련 없으면 "없음" 입력).
- 응답자 이메일 수집, 제출 후 응답 수정 허용, 진행률 표시가 켜져 있습니다.

## 참고
- Apps Script로는 "파일 업로드" 문항을 만들 수 없어 로고·사진은 **공유 링크**로 받도록 했습니다.
  파일 업로드를 원하면 편집 화면에서 해당 문항을 "파일 업로드" 유형으로 바꾸면 됩니다.
  (이 경우 응답자가 구글 로그인을 해야 하고, 파일은 내 드라이브 용량을 사용합니다.)
- 제품 섹션 수는 스크립트 상단 `MAX_PRODUCTS` 값으로 바꿀 수 있습니다.
